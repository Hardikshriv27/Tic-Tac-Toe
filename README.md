# Tic-Tac-Toe

A simple Tic-Tac-Toe game built with vanilla HTML, CSS, and JavaScript.

## Features

- Two-player gameplay
- Win and draw detection
- Restart button
- Responsive design
- No frameworks or dependencies

## Run locally

Open `index.html` in your browser.

## GitHub Pages

Push the project to a GitHub repository, then enable GitHub Pages from:

**Settings → Pages → Deploy from branch → main → / (root)**
